# 컨텍스트와 스킬 — 2026-10-29

전용 앱 오른쪽의 **컨텍스트 · 스킬**에서 관리한다.

## 컨텍스트 한도

**컨텍스트 한도 설정**에서 16384~131072 토큰을 1024 단위로 입력한다. 입력·이전 대화·도구 결과·출력이 공유하는 한도다. **저장만**은 다음 모델 로드에 반영하고, **저장 후 모델 재로드**는 현재 모델을 다시 시작한다. 실행 중인 요청이 있으면 변경하지 못한다. 오류가 나면 저장값과 실제 적용값을 확인하고 더 작은 한도로 재로드한다.

창은 저장값과 실제 엔진의 적용값을 구분하며, 대화 사용량은 Harness의 측정값이다. 새 대화나 모델 재로드 직후에는 측정 전이라고 표시한다. 큰 컨텍스트는 KV 메모리를 늘려 expert 캐시를 줄일 수 있다. 현재 기본값은 32768이다. 이번 UI의 128K 상한은 모델의 이론적 최대 길이를 뜻하지 않는다.

## 자동 압축과 즉시 압축

Strata/Harness의 기존 자동 압축을 사용한다. 모델별 출력 예산과 여유 공간을 남기도록 오래된 대화를 요약하며, 현재 32K 설정에서는 약 20071 토큰에서 압축을 검토한다. 도구 결과와 입력 길이에 따라 실제 실행 시점은 달라질 수 있다. 중간 도구 호출에도 자동 압축이 적용된다.

**지금 대화 압축**은 현재 세션에 `/compact`를 보내고 전후 사용률을 한국어로 표시한다. 입력 중인 초안은 보존한다. 모델에 전달할 오래된 문맥을 요약하는 기능이며 화면의 원본 대화 기록은 지우지 않는다. 요약은 일부 세부 사항을 잃을 수 있고, 최신 입력 한 건 자체가 너무 크면 메시지를 줄이거나 자료를 나눠 읽어야 한다.

## 스킬 관리

기본 스킬 세 개를 추가했다.

- **웹 조사와 출처 확인**: 공식 원문·게시일 확인, 실제 확인한 URL 제시, 자료 속 명령문을 지시로 취급하지 않기.
- **코드 수정과 검증**: 작업 지침과 코드 확인, 기존 변경 보존, 필요한 수정과 실제 테스트 결과 구분.
- **문서 요약과 작업 인계**: 목표·결정·미해결 문제·다음 작업 정리, 근거와 경로 보존, 비밀 제외.

**스킬 관리**에서 목록, 이름·설명·지침 편집, 활성화/비활성화, 새 스킬 생성과 직접 만든 스킬 삭제를 지원한다. 한국어 이름도 저장할 수 있다. 기본 스킬은 삭제 대신 비활성화할 수 있다. 변경 내용은 재시작 없이 다음 요청부터 Harness가 읽는다. 실제 사용한 스킬은 답변 아래에 표시한다.

`SKILL.md 불러오기`는 최대 64KiB의 지침 파일을 편집기에 가져온다. 내용을 검토하고 저장해야 설치된다. 지침 본문은 최대 40000자다. 스크립트·첨부 폴더를 포함한 스킬 패키지 설치는 지원하지 않는다. 내보내기는 현재 편집 내용이 반영된 `SKILL.md`를 내려받는다. 스킬은 필요할 때 모델이 읽는 지침이며, 활성화만으로 매번 실행되거나 추가 권한이 부여되지는 않는다.
