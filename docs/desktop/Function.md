# 사용자 흐름과 기능

1. 시작: 전용 앱 창을 열고 모델 준비 상태를 확인한다. 모델 누락과 엔진 오류는 원인을 표시한다.
2. 모델 준비: Qwen3.8 양자화, 저장 위치, RAM/VRAM/디스크 요구량을 확인한다. 다른 모델로 조용히 대체하지 않는다.
3. 대화: 한국어 입력, 스트리밍 출력, 작업 폴더 선택, 대화 기록과 재열기.
4. 도구: 파일 읽기/검색, 파일 수정, 명령 실행. Strata Manual 승인 흐름을 유지한다. 작업 폴더 선택을 OS 격리로 설명하지 않는다.
5. 웹: 검색과 페이지 읽기를 모델의 도구 호출로 수행한다. 검색 제공자 오류를 성공으로 표시하지 않고 결과 URL을 유지한다.
6. 중지: 사용자 요청을 취소하고 도구 실행 상태를 표시한다. 앱 종료 시 앱이 소유한 프로세스만 정리한다.
7. 관찰: RAM/VRAM, 모델과 엔진 이름, 생성 속도를 실제 값으로 표시한다. expert cache hit와 대화 cache hit를 구분한다. 측정하지 못한 값은 미지원으로 표시한다.
8. 설정: MCP와 검색 제공자 설정은 Strata 기능을 사용한다. 기존 설치의 API 키와 대화를 복사하지 않는다.

최초 검증은 단일 GPU, 단일 추론 슬롯, 텍스트와 도구 호출로 진행한다. 이미지와 다중 에이전트는 기본 경로 검증 이후 별도로 검증한다.
