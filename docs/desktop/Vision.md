# 이미지 입력

2026-10-29: `iq2_xs`를 CPU 비전 인코더로 로드하고 실제 Qwen + Harness로 이미지 인식을 검증했다. 이미지에만 적은 무작위 코드 `VD005F`를 그대로 반환했으며 컨텍스트 62,464를 유지했다. 사용자의 작업 폴더·응답 설정·원본 대화는 변경하지 않았다.

앱에서 F5를 누르면 오른쪽 **이미지 입력**에 끄기/CPU/GPU 선택과 **이미지 설정 적용 · 모델 재로드** 버튼이 표시된다. 현재 설정은 CPU이고 이미 로드되어 있으므로 바로 사용할 수 있다. 채팅의 **이미지 첨부**에서 PNG/JPEG/WebP를 선택하고 질문을 입력한다. 한 요청당 최대 4개, 파일당 2MiB다. 화면 캡처 도구 결과도 이미지 지원 경로로 전달된다.

첨부 픽셀은 요청으로 전송되며 Harness 기록에 포함될 수 있다. 브라우저 대화 목록에는 파일명만 저장해 localStorage 용량 초과를 줄인다. 원본 이미지의 미리보기·다운로드는 제공하지 않는다. CPU 비전은 VRAM을 expert 캐시에 남기지만 GPU 인코더보다 느릴 수 있다. 이 PC에서 GPU 비전은 이번 검증에 포함하지 않았다.

준비 파일은 `models/qwen38/models/mmproj-Qwen3.8-Flash-Next-BF16.gguf`다. Strata가 고정한 Hugging Face revision에서 907,543,008바이트를 내려받고 SHA256 `b1a82259702816a5330d7bd7607cd9676b11780e79ff7348c21103ff3ce49bd0`를 검증했다. `prepare_vision.py`는 모델 준비 전체를 재실행하지 않고 기존 설정을 백업한 뒤 비전 섹션만 추가한다. 비전 토큰 상한은 CPU 기본값 300이다.

일반 모델 로드와 컨텍스트 변경 후 재로드는 저장된 비전 선택을 유지한다. 어댑터의 image capability는 실제 실행 인스턴스의 vision 값으로 결정한다. 텍스트 전용 경로에 image capability만 강제로 덧붙이지 않는다.

검증 산출물은 Git에서 제외된 `.ram2vram-desktop/logs/vision/`에 있다. `verify_vision_live.py`는 유휴 모델을 재로드하고 새 무작위 코드 이미지로 검증하므로 모델 사용 중에는 실행하지 않는다. 작은 글자·복잡한 화면·여러 이미지에 대한 정확도는 이 단일 이미지 검증으로 보장하지 않는다.
